## Visão Geral
O Projeto Spring API é uma aplicação desenvolvida para estudo das APIs RESTful utilizando o framework Spring. A aplicação oferece funcionalidades básicas de CRUD (Create, Read, Update, Delete) para gerenciar recursos como usuários.

## Funcionalidades Principais

- **CRUD de Usuários:** Permite criar, ler, atualizar e deletar usuários através de endpoints RESTful.
- **Validação de Dados:** Implementa validações para garantir a integridade dos dados recebidos nas requisições.
- **Tratamento de Erros:** Fornece respostas apropriadas para diferentes tipos de erros, como recursos não encontrados ou dados inválidos.
- **Documentação da API:** Utiliza Swagger para gerar documentação interativa da API, facilitando o entendimento e teste dos endpoints.
- **Configuração de Banco de Dados:** Configura a aplicação para conectar-se a um banco de dados relacional, permitindo a persistência dos dados dos usuários.

## Tecnologias Utilizadas

- **Spring Boot:** Framework principal para o desenvolvimento da aplicação.
- **Spring Data JPA:** Para a interação com o banco de dados.
- **Spring Security:** Para a implementação de segurança na API.
- **Swagger:** Para a documentação da API.
